# ROHA 

ROHA is going to be a programming language. This will be compiled by the ROHA compiler. 
The front end of the compiler will form an intermediate representation of the code, 
this will then be optimised using constant folding, dead code elimination and common subexpression elimination.

At the end of compiling, the output will be an assembly file. This assembly file will then go through an assembler and linker.
Most likely, the assembler will be nasm and the linker used will be the ld linker.
